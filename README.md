# Тэйрин — прототип для Tabletop Simulator

## Как это устроено

Три факта о TTS, из которых следует всё остальное:

1. **Сцена — один JSON-файл** в `Saves\`. В нём объекты, их положение и
   *ссылки* на картинки. Самих картинок в файле нет.
2. **Картинка — это URL.** `file:///…` видит только этот компьютер,
   `https://…` — все.
3. **В онлайне сцена нужна только хосту.** Гости получают её от хоста и
   качают картинки по ссылкам сами.

Поэтому картинки лежат в этом репозитории и публикуются на GitHub, а сцена
ссылается на них по адресам `raw.githubusercontent.com`. Локальной и облачной
версии нет — есть одна сцена, и после `sync.py` её видят все.

## Одна команда

```
python sync.py
```

Запускать из этой папки после любой правки: таблицы карт, поля, фигурки,
скрипт. Она:

1. пересобирает картинки из исходников;
2. в живом сохранении TTS переписывает **только изменившиеся** объекты —
   ручная расстановка, повороты, масштаб остаются;
3. коммитит и пушит на GitHub — с этого момента картинки видят все;
4. если TTS запущен со сценой, подменяет изменённые объекты **прямо на
   столе**, без перезагрузки; если нет — увидите при следующей загрузке;
5. переписывает Chest (Objects → Saved Objects → Тэйрин).

`--dry-run` — только показать, что изменилось бы. `--no-push` — без
публикации (тогда и без подмены в игре: неопубликованные картинки игра не
скачает).

Сцену, расставленную руками в игре, сохраняйте как обычно (Save). Следующий
`sync.py` заберёт расстановку в репозиторий.

```
    scene.py       что в сцене принадлежит проекту: доски, фигурки; колоды находит сам
    tts_live.py    связь с запущенным TTS (порт 39999)
    gen_cards.py   листы карт из cards.xlsx
    gen_maps.py    поля локаций из гексов
    gen_art.py     фигурки, жетон, плитка перехода
    hexgrid.py     геометрия гекс-решётки
    global.lua     Global-скрипт сцены (сетка, подгонка размеров, второй ведущий)
    assets\        картинки; имя = ключ + хеш содержимого
    save\          копия сцены — то, что опубликовано

C:\1_Obsidian\...\Тэйрин\Карты\<Колода>\cards.xlsx   исходники карт (правятся руками)
C:\Users\...\My Games\Tabletop Simulator\Saves\TS_Save_1.json   живая сцена, её грузит TTS
```

Сохранение обязано лежать в папке TTS — из меню Save & Load игра читает
только её. В меню это слот «1». Цифра берётся из имени файла `TS_Save_1`;
сменить — одна строка `SLOT` в `paths.py`.

## Как объекты опознаются

Каждый объект проекта помечен в поле GMNotes строкой `teyrin:<ключ>@<хеш>`.
По ключу объект находится, по хешу видно, устарел ли. GUID и номера колод не
годятся — TTS их перенумеровывает при каждом сохранении. Метку видно только
ведущему при наведении, она безвредна; стирать не надо — без неё объект будет
опознан заново по названию и помечен снова.

Имя каждой картинки содержит хеш содержимого: `beast_face.257b82b1.png`.
Правка → новый хеш → новое имя → новая ссылка. Так ни кэш TTS, ни кэш GitHub
никогда не покажут старую картинку.

## Новая колода

Папка `Карты\<Название>\cards.xlsx` — и всё. Название колоды = имя папки.
Проще всего скопировать папку существующей колоды. Тип по колонкам:

| Колонки | Что это |
|---|---|
| `t_name, t_ap, t_stam, t_class, t_effect, b_*, affil` | карта действия, две половины через 180° |
| `name, effect, tipe` | снаряжение, одна сторона, общая рубашка |

Первая строка таблицы — пустая заготовка, так везде. Лист не шире 10 и не
выше 7 карт — предел TTS (70 карт на колоду).

## Новая доска или фигурка

Строка в `scene.IMAGES` (ключ, название, тип объекта, место по умолчанию) и
рисующая функция в `gen_art.py` или `gen_maps.py`, которая кладёт результат
через `paths.store(ключ, png)`.

## Скрипт сцены

`global.lua` — это Global-скрипт, как есть. Правка → `sync.py` → перезагрузить
сцену (Load): горячей подмены для скриптов нет. Что он делает: ставит
настройки сетки, подгоняет размер досок и фигурок под гексы, выдаёт Promote
второму ведущему (белый цвет).

## Карты во время игры

- Взять конкретную карту из колоды: правый клик по колоде → Search.
- Раздать: правый клик → Deal.
- Размножить: Ctrl+C / Ctrl+V.
- Любая карта, которой нет на столе: Objects → Saved Objects → Тэйрин →
  папка колоды — карты по номерам из таблицы, перетаскиваются мышкой.

## Игра по сети

Хостите вы: загрузили сцену, гости подключились. Больше ничего не нужно —
картинки уже на GitHub. Если хостить будет кто-то другой, ему нужен файл
`save\TS_Save_1.json` в его папку `Saves\`.

Мест за столом одиннадцать: десять игровых цветов и чёрное место ведущего
(оно одно, цвет не меняется). Второй ведущий садится белым и получает Promote
автоматически.

## Ограничения

- Горячая подмена колоды пересобирает её целиком: тасовка теряется. Карты,
  которые в этот момент лежат вне колоды (в руках, на столе), остаются
  старыми — перезагрузите сцену для чистого состояния.
- Репозиторий должен оставаться публичным.
- Папку `assets\` нельзя переименовывать: ссылки в сцене на неё.

## Установка

Python 3 с `pillow` и `openpyxl`; git с доступом к репозиторию.
